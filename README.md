NoxuApp

NoxuApp is a relaxation, wellness, and lifestyle application built around the original world of Pufi characters.

The app combines personalized night routines, relaxing sounds, mood-based activities, planning tools, brain-training games, collectible Pufi Cards, and customizable Pufi characters in a uniquely designed experience.

All Pufi characters, the visual identity, interface design, and the overall NoxuApp experience are originally created specifically for NoxuApp.

Privacy Policy

Data Collection: NoxuApp does not collect, process, sell, or share users' personal data with third parties.

Local Storage: User-created and app-related data is stored locally on the user's device. NoxuApp does not use an external server to store this data.

Account & Sign-In: NoxuApp does not require users to create an account or sign in.

Calendar Permission: NoxuApp may request access to the device's calendar only when the user chooses to add an activity or event to their calendar. Calendar access is used solely to provide this functionality. NoxuApp does not collect or transmit calendar data to external servers.

Notification Permission: NoxuApp may request permission to send notifications. Notifications are used only for app-related reminders and experiences requested or enabled by the user.

Data Transmission: NoxuApp does not transmit users' personal data to external servers or use it for advertising, tracking, or analytics purposes.

Data Deletion: NoxuApp stores its application data locally. When the application is deleted, its locally stored application data is removed from the device.

Privacy: NoxuApp is designed with a privacy-first approach. User information and app activity remain on the user's device.
